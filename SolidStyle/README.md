# SolidStyle – a SolidWorks-style workbench for FreeCAD 1.0

Pick **SolidWorks Style** in the workbench selector.

## What you get
- **CommandManager** ribbon with tabs underneath: Features, Sketch, Evaluate, Assembly, Drawing.
  Tools use SolidWorks names (Extruded Boss/Base, Extruded Cut, Hole Wizard, Shell, Convert Entities,
  Smart Dimension, Add Relation, Mate...). Hover a tool to see the FreeCAD name too.
- **Context tabs**: opening a sketch switches to the Sketch tab, a drawing switches to Drawing.
  You stay in this workbench when sketching (FreeCAD would normally jump to Sketcher).
- **Heads-up view toolbar** at the top of the 3D view: Zoom to Fit/Area, Section View,
  View Orientation, Display Style, Hide/Show, Appearance, Measure, Normal To.
- **Confirmation corner** (green tick / red cross) at the top right while a feature or sketch is open.
- **SolidWorks shortcuts**: Ctrl+1..7 standard views, Ctrl+8 Normal To, F zoom to fit,
  S shortcut bar, Ctrl+B rebuild. Clashing FreeCAD keys are borrowed only while this workbench is active.
- **SolidWorks naming**: Front/Top/Right Plane, Sketch1, Boss-Extrude1, Cut-Extrude1, Fillet1...
- **Mass Properties** dialog with a material/density picker.
- **New Part / New Assembly / New Drawing** (File menu and Quick Access toolbar).
- **Drawings**: Make Drawing from Part (ANSI sheet, scale, 3 views + isometric, title block, inches),
  Auto Dimension, Hole Callout, Save as PDF.
- **GD&T** (ASME Y14.5): Geometric Tolerance (feature control frames), Datum Feature, Basic Dimension.
- **Look & feel** (applied the first time): gradient background, grey parts with black edges,
  orange hover, blue selection, blue under-defined / black fully-defined sketches, middle-mouse rotate.
  *Tools > Restore My Settings* puts your previous settings back.

## SolidWorks-style feature workflows
- **Extruded Boss/Base / Extruded Cut** – click the tool first: pick a plane or face → the sketch opens →
  *Exit Sketch* (tick in the top-right corner) continues straight into the Extrude PropertyManager.
  A selected sketch, or the sketch you just finished, is used directly. End conditions: Blind, Up To Next,
  Through All (Up To Last), Through All – Both (cut), Up To Surface, Offset From Surface, Up To Body, Mid Plane;
  Reverse Direction, Draft (in/outward), Direction 2. Drag the blue arrow in the view to set the depth.
- **Revolved Boss/Base / Revolved Cut** – same flow; a centerline (construction line) in the sketch is picked
  as the axis automatically. Blind / Mid Plane, Direction 2.
- **Fillet / Chamfer / Shell** – pick edges/faces before or after clicking; Full or Partial preview,
  Delete removes an item from the list.
- **Hole Wizard** – pick a face → click hole centers (points) → Exit Sketch → choose type, size and end condition.
- **Assembly / Mate** – Insert Components, then Mate (or a type from Mate Types). No need to "activate" the
  assembly first: it is activated for you, and the first component is fixed automatically (like SolidWorks' (f)).
  Pick a face/edge on each of two components; the part moves to satisfy the mate. You need two components.
- Double-clicking one of these features re-opens the same panel (Edit Feature).
- Icons: SolidWorks-flavoured set (original artwork) in `solidstyle/icons/sw`, generated by
  `tools/make_icons.py` – edit and re-run it to tweak them.

## Differences from SolidWorks
- FreeCAD is Z-up: "Front Plane" is FreeCAD's XZ plane, "Top Plane" is XY.
- Mouse: middle-drag rotates, Shift+middle pans (Blender style; FreeCAD has no exact SolidWorks mode).
- Spacebar stays FreeCAD's show/hide; use Ctrl+1..8 or the heads-up View Orientation menu.
- Mates are FreeCAD joints: Concentric ~ Revolute/Cylindrical, Coincident ~ Distance 0, Lock ~ Fixed.
- Features live inside a Body, and FreeCAD needs one solid per Body.
- Not available yet: Thin Feature, Flip side to cut, From: Offset, Selected Contours.
- Patterns, Mirror, Sweep, Loft, Draft and Helix still use FreeCAD's own panels.
